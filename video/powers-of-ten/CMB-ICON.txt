CMB app object (2026-11-03)
Source: supplied WMAP five-year ILC RGB map; same hue-dependent shell opacity as the zoom. Interior is an illustrative 3D filament volume, not measured CMB structure.
Master PNG: content/icons/src/observable universe.png (2048 square, transparent).
Lighting: standard content/icons/src/sphere template.png, fixed to the viewer. Existing observable-universe generated cast shadow with faint refracted highlights remains registered separately.
Ordinary app: static WebP variants 128/256/512/1024. Narrated/video views: isolated rotating code object (src/cmb-object.js), perspective projection of interior filaments; 0.035 radians/second, about 180 seconds/orbit. Narration time determines angle; manual testing via ?cmb3d=1.
Measured isolated draw: about 5 ms at 256 square on this machine. No terrain, galaxy catalogue, density point cloud or Lenia is loaded. A full orbit sequence would duplicate hundreds/thousands of images and constrain output size; retain code for now. Falls back to the PNG if WebGL is unavailable.
