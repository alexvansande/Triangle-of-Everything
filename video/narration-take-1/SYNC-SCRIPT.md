# Sync script: narration take 1 ↔ the app

Timecodes refer to `narration-edit.m4a` (12:49). The **Step** column is the tour step id (`src/tour-data.js`), so `D` / `A` step to it. Object names match `src/objects.json`, so you can find them with the app's search.

**Capture setup**
- `V` once: 1920×1080 recording stage. Press it twice for 9:16 if you also want a Shorts/Reels cut.
- `H` hides the zoom buttons and category bar. `R` resets everything before each take.
- `Z` / `X` slow down or speed up animations. Tour fly-tos usually look best recorded slow and sped up in the edit.
- `W` / `S` zoom, arrow keys pan. Two-finger trackpad drag also pans smoothly.
- Record **one clip per section**, not one 13-minute take. The audio already has about 0.9 s gaps between sections for the cuts.
- For "click an object": its info panel opening is a nice beat, but close it before the next fly-to.
